# Память Red Team и Аудитора: AUDIT_DECISIONS.md

## 1. Зафиксированные дефекты и решения
* **Роутинг и навигация:**
  - *Проблема:* клик «Назад» в браузере закрывал сайт.
  - *Решение:* внедрить `history.pushState` и обработчик `window.onpopstate` для синхронизации хэша экранов (`#screen-cultures`, `#screen-quest`).
* **Доступность (A11y/WCAG 2.1 AA):**
  - *Проблема:* карточки квеста и культур были сверстаны тегами `<div>` без клавиатурного фокуса.
  - *Решение:* обязательны теги `<button>` либо атрибуты `role="button"` и `tabindex="0"`.
* **Производительность (Reflow / Scroll):**
  - *Проблема:* `getBoundingClientRect()` вызывался на каждый тик `mousemove` в лупе-сканере.
  - *Решение:* перенести расчеты в `requestAnimationFrame` с `transform: translate3d`.
* **Zero Runtime LLM:**
  - *Решение:* в рантайм `index.html` не передаются внешние ключи. Все генерации производятся оффлайн через `studio/`.
