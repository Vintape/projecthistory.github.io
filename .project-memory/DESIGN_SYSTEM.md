# Память Креативного Директора: DESIGN_SYSTEM.md

## 1. Миссия и визуальный код проекта «АРТЕФАКТ»
Сайт должен выглядеть как **цифровой филиал ведущего национального музея** (уровня Эрмитажа или Лувра). 
Категорически запрещен вид шаблонного стартапа или студенческой поделки.

## 2. Шрифтовой канон
* **Заголовки 1-го уровня (Hero, Splash):** `Monomakh` — аутентичный старославянский/древнерусский устав с полной кириллицей.
* **Редакционные тексты и лонгриды мифологии:** `Cormorant Garamond` — академическая антиква. Кернинг: оптический.
* **Музейные даты, инвентарные номера, таймкоды:** `Montagu Slab` — лапидарный брусковый шрифт.
* **Интерфейс, кнопки, навигация:** `Montserrat` (чистый нейтральный гротеск, трекинг `+0.04em` для кнопок капсом).

## 3. Цветовой код (Palette Tokens)
* `--bg-main`: `#070d1e` (глубокий имперский индиго)
* `--bg-card`: `#0e1933` (ночной кобальт)
* `--gold`: `#c99c52` (сусальное античное золото)
* `--gold-light`: `#f3d08a` (золотой отблеск)
* `--ruby`: `#c83428` (рубиновая киноварь)
* `--cyan`: `#48cae4` (лазурный свет)
* `--parchment`: `#f5eee2` (натуральный льняной пергамент)

## 4. Запрещенные анти-паттерны (Blacklist)
❌ Кислотный синий (`#00f`, `#3b82f6`) и неоновый фиолетовый.
❌ Огромные скругления `rounded-3xl` (кнопки в форме таблеток со смайликами). Разрешены строгие скругления `4px–10px`.
❌ Дешевые размытые тени `box-shadow: 0 20px 50px rgba(0,0,0,0.8)`. Вместо них — деликатные субпиксельные рамки `1px solid rgba(201, 156, 82, 0.25)`.
❌ Рекламный пафос: слова «уникальный», «окунитесь», «не секрет, что». Только сдержанный инфостиль музейного гида.
