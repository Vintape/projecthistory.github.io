# Первоисточник

Семейный веб-атлас для исследования своих корней через историю и культуру регионов. В интерфейсе доступны Ленинградская область с отдельной схемой Старой Ладоги, Санкт-Петербург, Пермский край и Иркутская область.

## Запуск

```sh
python3 app.py
```

Откройте [приложение](http://127.0.0.1:8765/). Нужен Python 3.10 или новее. Для другого порта используйте `python3 app.py --port 8766`.

## Публикация

[Открыть MVP на GitHub Pages](https://vintape.github.io/projecthistory.github.io/mvp/). Папка `mvp/` в ветке `main` содержит только сборку интерфейса. Исходники публикуются в ветке `codex/pervoistochnik-mvp`.

На GitHub Pages семейные профили и маршруты хранятся в отдельном проекте Supabase. Для работы с сайтом нужно создать семейный профиль онлайн. Локальный запуск использует SQLite.

```sh
supabase link --project-ref mkseudrxstywbmzxgenl
supabase db push
cp pilot_catalog.json supabase/functions/atlas/pilot_catalog.json
supabase functions deploy atlas
python3 scripts/build_pages.py --api-url https://mkseudrxstywbmzxgenl.supabase.co/functions/v1/atlas --output .runtime/pages/mvp
```

Задайте `YANDEX_API_KEY` и `YANDEX_FOLDER_ID` в секретах Edge Functions, чтобы ИИ-ассистент отвечал через ЯндексGPT в обоих возрастных режимах. Для опубликованного сайта действует общий лимит в 100 обращений к модели в сутки по Москве.

## Что можно показать

1. Выберите регион на карте или в списке и откройте одну из его точек. Увеличивайте карту кнопками, колёсиком с Ctrl или жестом двумя пальцами на телефоне. При увеличении карту можно двигать.
2. Сравните детские и взрослые описания. Выберите сказание, фильм или персонажа и откройте источник материала.
3. Задайте вопрос ИИ-ассистенту о выбранной точке или другом месте. При настроенном ключе ответ даёт ЯндексGPT.
4. Соберите маршрут на день, выходные или онлайн. Семейный кабинет сохраняет маршруты, их можно открыть в летописи и распечатать или сохранить в PDF.

Тест о семейных корнях доступен в Telegram. [Открыть бота «Династия»](https://t.me/DynastiyaRussiaQuizBot)

При локальном запуске семейные сведения и маршруты хранятся в SQLite-базе `.runtime/family.sqlite3`. Переменная `PERVOISTOCHNIK_DB` меняет путь к базе. Карта иллюстративная, региональные схемы показывают примерное расположение мест. Атрибуция фотографий приведена в [сведениях о регионах](public/assets/pilot-region-credits.md) и [материалах Старой Ладоги](public/assets/ladoga-credits.md).

## Проводник и каталог

ИИ-ассистент использует `/api/guide`. Когда в вопросе назван регион или объект, это название важнее текущего выбора на карте. ЯндексGPT может отвечать за пределами каталога. Ссылки добавляются для использованных материалов из каталога. При сбое облачного ответа используется поиск по каталогу. Маршрут собирается из мест и материалов каталога с учётом формата, интересов, возрастного режима и сохранённой географии семьи.

Для локальной настройки запустите `python3 app.py --configure-yandex`, введите ID каталога и API-ключ со скрытым вводом. Настройки хранятся в локальном файле `.runtime/yandex.json`, который исключён из Git. После изменения настроек перезапустите приложение. Вместо файла можно задать в окружении обе переменные `YANDEX_API_KEY` и `YANDEX_FOLDER_ID`. [Документация Yandex AI Studio](https://aistudio.yandex.ru/ru/docs/ai-studio/quickstart/)

Модель получает вопрос и открытый контекст места. Возраст, география предков, данные аккаунта и сохранённые маршруты из профиля ей не передаются.

## Добавление регионов и партнёрских материалов

Каждый регион в `pilot_catalog.json` имеет стабильный идентификатор, маркер, поисковые варианты названий, историю, культурный контекст и материалы. Точки связываются с регионом через `regionId`. Поле `contentRefs` позволяет использовать один источник в нескольких карточках. Географические координаты точек применяются в схеме региона и подборе маршрута.

Для библиотек, музеев и издательств достаточно пока импортировать редакционные карточки с типом, заголовком, возрастной маркировкой, обложкой с атрибуцией и ссылкой на первоисточник. Проигрыватель использует только поддерживаемые источники, у каждой карточки есть переход к публикации.

В «Следующем шаге исследования» доступна демонстрационная памятка о подготовке к консультации. Для реальной консультации нужны кабинет партнёра и согласие на передачу выбранных пользователем сведений. Летопись служит основой будущей семейной книги. Для заказа книги понадобятся макет, согласование с семьёй и интеграция с типографией и оплатой. Платежи и бронирование в текущем MVP отсутствуют.
