# Первоисточник

Семейный веб-атлас о народах России. На главной — иллюстрированная карта России на светлом фоне. Нажмите **Ленинградская область** или **Точки Старой Ладоги**, чтобы открыть схему с тремя местами.

## Запуск

```sh
python3 app.py
```

Откройте [приложение](http://127.0.0.1:8765/). Нужен Python 3.10 или новее. Для другого порта используйте `python3 app.py --port 8766`.

## Публикация

[Открыть MVP на GitHub Pages](https://vintape.github.io/projecthistory.github.io/mvp/). Папка `mvp/` в ветке `main` содержит только сборку интерфейса. Исходники публикуются в ветке `codex/pervoistochnik-mvp`.

На GitHub Pages семейные профили и маршруты хранятся в отдельном проекте Supabase. Для работы с сайтом нужно создать семейный профиль онлайн. Локальный запуск использует SQLite.

```sh
supabase link --project-ref mkseudrxstywbmzxgenl
supabase db push
cp pilot_catalog.json supabase/functions/atlas/pilot_catalog.json
supabase functions deploy atlas
python3 scripts/build_pages.py --api-url https://mkseudrxstywbmzxgenl.supabase.co/functions/v1/atlas --output .runtime/pages/mvp
```

Для облачного ЯндексGPT задайте `YANDEX_API_KEY` и `YANDEX_FOLDER_ID` в настройках секретов Edge Functions. Без них онлайн-«Проводник» работает в демонстрационном режиме.

## Что можно показать

1. На обзорной карте выберите Ленинградскую область, затем одну из точек Старой Ладоги. Переключите детский и взрослый режимы, чтобы сравнить описания.
2. Откройте сказку, фильм или персонажа. Сказания сопровождаются ссылками на открытые PDF. Фильм «Белая Весь. Вепсское искусство» можно смотреть на сайте или в публикации Президентской библиотеки. У каждого фильма есть ссылка на источник.
3. Отправьте сообщение в «Проводнике» или в «Чате с экспертами». В демонстрационном режиме оба чата отвечают «ДИНАСТИЯ!!!». Если настроен ЯндексGPT, во взрослом «Проводнике» можно включить отправку вопросов в облако. В «Проводнике» доступна озвучка, если браузер поддерживает синтез речи.
4. Соберите маршрут на день, выходные или онлайн. Зарегистрируйте семейный профиль, сохраните маршрут и откройте летопись для печати или экспорта в PDF через браузер.

Данные семьи и маршруты хранятся в локальной SQLite-базе `.runtime/family.sqlite3`. Переменная `PERVOISTOCHNIK_DB` меняет путь к базе. Обзорная карта иллюстративная. Схема памятников показывает примерное расположение мест и не заменяет навигатор. Координаты и источники находятся в `pilot_catalog.json`, авторы изображений — в [`public/assets/ladoga-credits.md`](public/assets/ladoga-credits.md).

## Проводник и каталог

Для поиска по редакционному каталогу сервер поддерживает `/api/guide`. Если ЯндексGPT не вернул ответ с источниками, «Проводник» показывает результат поиска по каталогу. Маршрут собирается из мест и материалов каталога с учётом формата, интересов, возрастного режима и сохранённой географии семьи.

Для локальной настройки запустите `python3 app.py --configure-yandex`, введите ID каталога и API-ключ со скрытым вводом. Настройки хранятся в локальном файле `.runtime/yandex.json`, который исключён из Git. Перезапустите приложение и включите «Отправлять вопросы в ЯндексGPT» во взрослом режиме. При запуске можно вместо файла задать в окружении обе переменные `YANDEX_API_KEY` и `YANDEX_FOLDER_ID`. [Документация Yandex AI Studio](https://aistudio.yandex.ru/ru/docs/ai-studio/quickstart/)

Модель получает вопрос и открытый контекст места. Возраст, география предков, данные аккаунта и сохранённые маршруты из профиля ей не передаются.

Карточки пилота редактируются в `pilot_catalog.json`. Три точки Старой Ладоги доступны целиком. Остальные точки общей карты сообщают о текущем покрытии. Подписка, заказ печати и кабинет партнёров относятся к следующему релизу.
